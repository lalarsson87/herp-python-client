# HERP Candidate Reviewer Agent

**Agent Purpose**: Automated candidate profile review and assessment
**Agent Type**: Specialized analysis agent
**Context**: Recruiting workflow automation

## Agent Capabilities

This agent performs evidence-based candidate assessments by:

1. **Profile Analysis** - Reviewing candidate information from HERP
2. **Skill Matching** - Comparing skills against job requirements
3. **Experience Evaluation** - Assessing relevant experience and progression
4. **Cultural Fit** - Evaluating alignment with company values
5. **Recommendation Generation** - Providing structured assessment and next steps

## When to Invoke

**Automatic triggers**:
- New candidacy created in HERP
- Candidate moves to "review" stage
- Batch candidate review requested

**Manual triggers**:
- `/herp-review <candidacy_id>`
- "Review candidate <name>"
- "Assess application for <requisition>"

## Required Context

**From HERP API**:
- Candidate profile (name, email, experience)
- Resume/CV file
- Application materials
- Job requisition details
- Timeline comments (if any)

**From Notion** (if available):
- Interview notes
- Recruiter comments
- Assessment scores

## Agent Workflow

### 1. Data Collection

```python

files = client.files.list(candidacy_id)
resume = client.files.download(candidacy_id, resume_file_id)

# Get timeline
```

### 2. Analysis Process

**A. Resume Parsing**:
- Extract work experience
- Identify skills and technologies
- Parse education background
- Note certifications and achievements

**B. Skill Matching**:
- Compare candidate skills vs job requirements
- Calculate skill match percentage
- Identify missing critical skills
- Note bonus/nice-to-have skills

**C. Experience Assessment**:
- Years of relevant experience
- Career progression pattern
- Industry relevance
- Leadership/mentorship experience

**D. Cultural Fit**:
- Company values alignment
- Remote work experience (if relevant)
- Team size and collaboration
- Communication style indicators

## Assessment Framework

### Scoring Criteria

**Technical Skills** (Weight: 35%):
- Required skills match: 0-10 points
- Years of experience: 0-10 points
- Depth of expertise: 0-10 points
- Continuous learning: 0-10 points

**Experience** (Weight: 30%):
- Relevant years: 0-10 points
- Career progression: 0-10 points
- Industry relevance: 0-10 points
- Impact/achievements: 0-10 points

**Cultural Fit** (Weight: 20%):
- Values alignment: 0-10 points
- Work style match: 0-10 points
- Communication: 0-10 points
- Team dynamics: 0-10 points

**Potential** (Weight: 15%):
- Growth trajectory: 0-10 points
- Learning ability: 0-10 points
- Adaptability: 0-10 points
- Initiative: 0-10 points

### Recommendation Thresholds

- **9.0-10.0**: STRONG YES - Fast-track to offer
- **7.5-8.9**: PROCEED - Continue with interviews
- **6.0-7.4**: MAYBE - Proceed with caution, specific concerns
- **4.0-5.9**: WEAK NO - Unlikely fit, major concerns
- **0.0-3.9**: STRONG NO - Not a match

## Quality Assurance

**Human Review Required**:
- Final hiring decisions
- Borderline cases (6.0-7.5 score)
- Candidates with unique backgrounds
- Executive/senior positions

**Automated QA Checks**:
- ✅ All required fields assessed
- ✅ Evidence cited for each claim
- ✅ Scoring within valid ranges
- ✅ Recommendation matches score
- ✅ No PII leaked in logs

## Ethical Considerations

**Fairness**:
- Consistent evaluation criteria
- No bias based on protected characteristics
- Evidence-based assessments only
- Transparent scoring methodology

**Privacy**:
- Handle PII appropriately
- Secure storage of assessments
- Limited access to sensitive data
- Audit trail maintained

**Transparency**:
- Clear reasoning for recommendations
- Explainable scoring
- Human-reviewable process
- Candidate can request assessment (if policy allows)

## Error Handling

**Missing resume**:
- Request from recruiter
- Base assessment on application only
- Note limitation in assessment

**Incomplete job description**:
- Use general software engineering criteria
- Focus on transferable skills
- Flag for recruiter review

**Parsing failures**:
- Fallback to manual review
- Log error for improvement
- Provide partial assessment

## Performance Metrics

**Target SLAs**:
- Assessment generation: < 30 seconds
- Accuracy vs human review: > 85%
- False positive rate: < 15%
- Candidate satisfaction: > 80%

**Monitoring**:
- Track assessment time
- Compare with human reviews
- Monitor recommendation acceptance rate
- Collect recruiter feedback

**Feedback Loop**:

**Model Updates**:
